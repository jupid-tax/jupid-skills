# Source Policy

Use official authority as the source of truth. Treat everything else as a lead.

## Primary official sources

Use these sources first:

- Internal Revenue Code: `https://uscode.house.gov/`
- Treasury Regulations: `https://www.ecfr.gov/`
- IRS forms and instructions: `https://www.irs.gov/forms-instructions`
- IRS publications: `https://www.irs.gov/publications`
- IRS notices, revenue procedures, and revenue rulings:
  `https://www.irs.gov/irb/`
- Official IRS topic pages and FAQs: `https://www.irs.gov/`

## Secondary sources

Use only when the user asks for broader context, when official sources are hard
to locate, or as leads to primary authority:

- Tax software help pages
- CPA firm articles
- Law firm articles
- Journal articles
- Search snippets
- Prior agent notes
- Internal workpapers

Do not cite secondary sources as final support for a rule if an official source
is available.

## Source freshness

For annually changing values, do not rely on model memory. Verify the current
tax year against an official source.

Examples of year-dependent values:

- standard deduction
- tax brackets
- mileage rates
- Section 179 limits
- retirement plan limits
- HSA limits
- Social Security wage base
- underpayment and interest rates
- penalty amounts

If the current-year source has not been released, state that the value is not
yet determined from official sources and cite the latest available source only
as historical context.

## Pinpoint standards

Every authority should include the most specific available pinpoint:

- IRC: section and subsection, e.g. IRC Section 162(a)
- Regulation: section and paragraph, e.g. Treas. Reg. Section 1.263(a)-1(f)
- Form instruction: form, tax year, page, line, worksheet, or heading
- Publication: publication number, tax year, chapter/heading, page if available
- Revenue Procedure / Notice: section, table, or page
- IRS page: page title and heading or question number

## Conflict handling

If official sources conflict or appear to conflict:

1. Quote or summarize both positions with citations.
2. Identify which source is more authoritative for the narrow issue.
3. Do not silently harmonize the conflict.
4. Label the conclusion as uncertain if the hierarchy does not resolve it.
