# Submitting an Installment Agreement Request (or Skipping Form 9465)

How an agent takes the user from "I can't pay my tax bill" to a submitted payment plan request. Form 9465 is one of several channels and often not the cheapest. The agent's first job is routing.

Sources (re-check before each use; fees and thresholds change):
- Instructions for Form 9465 (Rev. July 2024), "Who should use this form?", "Where To File": https://www.irs.gov/pub/irs-pdf/i9465.pdf
- IRS, Payment plans; installment agreements (fees updated March 3, 2026; last reviewed 13-Aug-2026): https://www.irs.gov/payments/payment-plans-installment-agreements
- IRS, Online payment agreement application (last reviewed 14-Sep-2026): https://www.irs.gov/payments/online-payment-agreement-application
- About Form 9465 (last reviewed 29-Apr-2026): https://www.irs.gov/forms-pubs/about-form-9465

## Channel decision tree

```
Are all required returns filed?
  No  → STOP. File the missing returns first; a request is denied if any required
        return is unfiled (i9465).
  Yes ↓
In bankruptcy, or an offer in compromise pending/accepted?
  Yes → STOP. Do not file Form 9465. Call 800-829-1040 (i9465).
  No  ↓
Is the debtor an operating business owing employment/unemployment tax,
or a corporation/partnership?
  Yes → Not Form 9465. Call the number on the notice or 800-829-4933
        (i9465; OPA page: business accounts cannot apply online).
  No  ↓ (individual, or sole proprietor including a closed one)
Can the user pay in full now?
  Yes → Pay (Direct Pay, Online Account, EFTPS, check, card). $0 setup.
  No  ↓
Can the user pay in full within 180 days?
  Yes → Short-term plan: OPA online (individuals) or phone. $0 setup.
        Balance limit: "less than $100,000" (irs.gov) / "$100,000 or less" (i9465).
  No  ↓
Combined tax + penalties + interest ≤ $50,000 and user can use an IRS Online Account?
  Yes → OPA long-term: $29 with direct debit, $69 without (irs.gov).
        Use Form 9465 only if the user declines OPA (record the choice).
  No  ↓
Form 9465 (paper), fee $107 with direct debit / $178 without (irs.gov):
  - Filing a return now with a balance? → attach Form 9465 to the FRONT of the return
    and mail to the return's address from the return instructions.
  - Return already filed, or answering a notice? → mail Form 9465 alone to the
    i9465 table address (below).
  - Line 9 > $50,000, or payment below line 10 and cannot increase → attach Form 433-F.
Prefer to talk to someone? → 800-829-1040 (individuals), 800-829-4933 (business),
or the number on the notice.
```

## Channel 1 — Online Payment Agreement (OPA)

URL: https://www.irs.gov/payments/online-payment-agreement-application (IRS.gov/OPA)

Eligibility (OPA page): long-term plan if the user owes $50,000 or less in combined tax, penalties and interest and has filed all required returns; short-term plan if the user owes less than $100,000. Sole proprietors and independent contractors apply as individuals.

Pre-flight:
- IRS Online Account (photo identification needed to create it).
- Bank routing and account numbers if choosing direct debit.
- If the return was just filed and no balance notice has arrived, the balance due shown on the return.

Representative (POA) path: the representative needs a Tax Pro Account or applies offline; Form 2848 must be on file first and must cover every tax period with a balance (OPA page). Not all Form 2848 authority levels can set up payment plans; check the Form 2848 instructions.

What the agent may do: walk the user through screens they operate. The user logs in, the user types bank numbers, and the user clicks submit. The OPA page says the user gets an immediate approval or denial notice.

---

## Channel 2 — Phone

- Individuals: 800-829-1040. Business: 800-829-4933. Or the number on the notice (irs.gov payment plans page).
- Phone and mail requests pay the higher column of fees.
- Before the call, give the user a one-page summary: balances by period, proposed payment, payment day, payment method.

---

## Channel 3 — Form 9465 attached to a return

- Attach Form 9465 to the **front** of the return and mail it to the address in the return's instructions (i9465 "Where To File"). The i9465 address tables below do **not** apply in this case.
- Make any payment with the return as its instructions describe (i9465 "Line 8").
- If the user e-files the return through software that offers Form 9465, ask the user to confirm the software includes it with the e-filed return; this skill does not assume any particular software supports it.
- Reply timing: usually within 30 days; longer for a return filed after March 31 (i9465 "Requesting an installment agreement").

### Package checklist (standalone)

- [ ] Form 9465, both spouses signed if joint
- [ ] Check or money order for line 8, payable to "United States Treasury", with name, address, SSN/EIN, daytime phone, tax year and return on it (if line 8 > 0)
- [ ] Form 433-F, signed, if required (line 9 > $50,000 or 11b box checked)
- [ ] Form 2159 with the employer portion signed, if line 14 is checked
- [ ] Part II on page 2, if the three Part II conditions apply
- [ ] Copy of everything kept by the user
- [ ] Certified mail with return receipt recommended for proof of mailing

## After submission

1. **Pending**: the IRS generally may not levy while the request is pending; the collection period is suspended or prolonged (i9465 note; irs.gov).
2. **Decision**: usually within 30 days (longer for returns filed after March 31). Approval notice states the terms, the first due date, and the user fee.
3. **If no reply by the chosen payment day**: send the first payment to the same service center address used above, or pay at IRS.gov/Payments (i9465 "Line 12").
4. **Rejected**: the collection period is suspended for 30 days after rejection; the user may appeal through the Collection Appeals Program (irs.gov payment plans page; Publication 1660).
5. **Low-income fee not applied**: Form 13844 within 30 days of the acceptance letter date. Address conflict: Form 13844 (Rev. 2-2026) prints Fresno, CA (IRS ACS Correspondence, P.O. Box 24017, Stop 76101, Fresno, CA 93779); the irs.gov payment plans page prints Kansas City, MO (PO Box 219236, Stop 5050, Kansas City, MO 64121-9236). Use the address on the form revision being mailed and tell the user about the conflict.

## Consent and security rules

These are not optional.

1. **The user decides the channel.** Present the fee difference between OPA and paper; record the user's choice.
2. **The user signs.** Never sign, never generate a signature image, never type a signature on the user's behalf. On a joint return both spouses sign; the direct debit is not approved otherwise (i9465).
3. **Direct debit needs explicit consent.** Lines 13a/13b carry an ACH authorization that stays in force until revoked (revocation: 1-800-829-1040 at least 14 business days before the settlement date). Read that text to the user and get an explicit "yes" before filling 13a/13b.
4. **Bank numbers and SSNs are collected only at fill time.** Do not store them in memory, logs, notes, or summaries. Mask them in drafts (last 4 only) unless the user asks to see full values to transcribe.
5. **No invented figures.** Every dollar amount comes from a return, a notice, a transcript, the user's statements, or the user's documents. If a figure is missing, ask and stop.
6. **Do not submit online for the user.** In OPA the user logs in and clicks submit. The agent can explain screens.
7. **Third-party contact.** The signature block authorizes the IRS to contact third parties to process the request. Tell the user before they sign.
8. **If anything comes back** (rejection, request for Form 433-F, default notice), show it to the user and let them decide; do not resubmit automatically.
