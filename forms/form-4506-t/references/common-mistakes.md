# Form 4506-T Common Mistakes

Form 4506-T looks simple — one page, a few boxes. But requests get rejected or delayed for predictable reasons. Here are common errors and how to avoid them (rules from Form 4506-T, Rev. April 2025, page 2).

---

## 1. Multiple transcript types selected

**Mistake**: User checks both 6a (Return Transcript) and 6b (Account Transcript) on the same form, hoping to get both.

**Why it's risky**: The form allows only one tax form number per request (line 6). It does not state that checking several transcript boxes gets the form rejected, but one transcript type per form keeps each request unambiguous.

**Fix**: File **separate** Form 4506-T forms — one per type — or use 6c. Both can be mailed/faxed together, but each is its own form.

If the user needs multiple types for the same year, also consider:
- 6c (Record of Account) — combines 6a + 6b in one document. Saves a form.
- Individual Online Account — all five types, free, immediate once verified.

---

## 2. Signature older than 120 days

**Mistake**: User signs the form, sets it aside, mails it 6 months later when the lender finally asks. IRS rejects with "signature too old."

**Why it's wrong**: The IRS must receive Form 4506-T within **120 days** of the date the taxpayer signed it, or it will be rejected (form page 2, "Signature and date").

**Fix**: Sign close to the submission date. If the user is preparing the form in advance, leave the signature field blank and have them sign right before mailing/faxing.

---

## 3. Wrong address on Line 4

**Mistake**: User filled Line 4 with the address they lived at "back when [some event]" rather than the address on the most recent tax return filed.

**Why it's wrong**: Line 4 is for the **previous address shown on the last return filed** if different from line 3, not arbitrary prior addresses.

If the user has not moved since their last return, Line 4 should be **blank**.

If the user has moved since the last return, Line 4 = address on most recent return; Line 3 = current address.

**Fix**: Confirm with the user the address on their most recent return. If lines 3 and 4 differ and the user has not changed the address with the IRS, file Form 8822 — transcripts are mailed only to the address of record.

---

## 4. Unchecked authority box in the signature area

**Mistake**: The user signs and dates the form but leaves the "Signatory attests ... authority to sign" box unchecked. (A related myth: that both spouses must sign for a joint-return transcript. They don't — transcripts of a joint return may be furnished to either spouse, and only one signature is required.)

**Why it's wrong**: The form says it will not be processed and will be returned if the box is unchecked (form page 2, Caution).

**Fix**: Check the box before signing. On a joint return, one spouse's signature is enough.

---

## 5. Form filled for "current year" but return not yet processed

**Mistake**: User filed their 2024 return in late February, then immediately submitted Form 4506-T for tax year 2024 in early March. IRS rejects.

**Why it's wrong**: For a refund or no-balance-due return, the IRS says to allow 2-3 weeks after e-filing and 6-8 weeks after mailing a paper return before requesting a transcript; balance-due returns paid after filing take 3-4 weeks after full payment, and unpaid balance-due returns are processed in mid-May (https://www.irs.gov/individuals/transcript-availability).

**Fix**: Wait for the return to be processed before requesting a transcript. Use the timing table on the transcript-availability page, or check refund status at https://www.irs.gov/refunds.

If the user needs the transcript urgently for a deadline-driven application (mortgage closing, etc.) and the return isn't yet processed, alternatives:
- Tax Account Transcript may be available faster than Return Transcript
- Provide the lender with the actual filed return + acknowledgment of e-file acceptance instead of waiting

---

## 6. Wrong year format

**Mistake**: User enters "2024" on Line 9 instead of "12/31/2024".

**Why it's wrong**: Line 9 asks for the end date of the tax year or period in mm/dd/yyyy format ("Example: Enter 12/31/2018 for a calendar year 2018 Form 1040 transcript").

**Fix**: Format as 12/31/YYYY for calendar-year filers. For fiscal-year filers, use the actual fiscal year-end (e.g., 06/30/2024).

---

## 7. Asking for a transcript for a year not yet ended

**Mistake**: In November 2025, user enters 12/31/2025 on Line 9, expecting to get a "current-year-in-progress" transcript.

**Why it's wrong**: The 2025 tax year doesn't conclude until 12/31/2025. There is no return to transcript before the tax year ends and the user files. The earliest a 2025 transcript becomes available is ~2-3 weeks after the user files in early 2026.

**Fix**: Wait until the user has filed and the return has been processed. For mid-year financial verification, the user can provide:
- Year-to-date pay stubs from employer
- Most recent W-2 (last full year)
- Bank statements for income evidence

---

## 8. Wage and Income Transcript requested too early

**Mistake**: In February 2026, user requests the 2025 Wage and Income Transcript expecting to see all their W-2s and 1099s.

**Why it's wrong**: irs.gov says current-processing-year information is generally available online in the first week of February, but the transcript only shows documents already filed with the IRS, so early in the year it may be incomplete. The form's line 8 text says current-year information is generally not available until the year after it is filed.

**Fix**: For the most current year, tell the user the transcript may be incomplete and check again later; for prior years, data is available year-round.

If the user needs W-2 data urgently and their employer's W-2 wasn't received:
- Contact employer to reissue
- Last resort: Form 4852 (Substitute for W-2) — file return with estimated W-2 data and an explanation

---

## 9. Sending to wrong RAIVS office

**Mistake**: User mails Form 4506-T to the IRS office address from a 2018 instruction page (or a Google search result for "IRS Form 4506-T address").

**Why it's wrong**: IRS RAIVS office addresses change over time. Old addresses may forward, but often delays processing. Worse, the wrong office may simply return the form.

**Fix**: Use the charts on **page 2 of the current Form 4506-T** (downloaded fresh from https://www.irs.gov/pub/irs-pdf/f4506t.pdf). There are two charts — individual transcripts (Form 1040 series, W-2, 1099) and all other transcripts — and each maps the state the user lived in (or the business was in) **when the return was filed** to the Austin, Kansas City, or Ogden RAIVS Team with an address and fax number. The same state can route differently in the two charts (e.g., Georgia: Austin for individual, Kansas City for all other).

---

## 10. Treating Line 5 as a third-party mailing address

**Mistake**: User writes the lender's name and address on Line 5 expecting the IRS to mail the transcript to the lender.

**Why it's wrong**: Line 5 is only a customer file number (up to 10 numeric characters printed on the transcript). Since July 2019 the IRS mails Form 4506-T transcripts only to the taxpayer's address of record; a lender that wants transcripts directly must use IVES with Form 4506-C (form, note under line 5 and "What's New"). Entering letters, an SSN, or a name on Line 5 makes the IRS print "9999999999" instead.

**Fix**:
- Put only digits (≤10) on Line 5, e.g., the numeric part of a loan number, or leave it blank
- The user forwards the transcript to the lender, or signs the lender's Form 4506-C

---

## Bonus: 11. Confusing 4506 vs. 4506-T vs. 4506-C

This one's so common it deserves an honorable mention.

| Form | What it gets | Cost | Turnaround |
|------|--------------|------|-----------|
| 4506 | Full COPY of return with attachments | $30 per return | up to 75 calendar days |
| 4506-T | Transcript (summary) of return | FREE | most within 10 business days, plus mail |
| 4506-T-EZ | Individual tax return transcript only | FREE | by mail |
| 4506-C | IVES transcript (lender-driven) | $4 per transcript, charged to the IVES participant | near real time when authorized online |

If the user has been told to fill out "Form 4506" but the lender just wants income verification, the **transcript** is usually enough — save the user $30 per return.

If the user has Form 4506-C from a lender, sign that and give it back. Don't also fill out 4506-T.

---

## Validation the agent should run

Before submitting Form 4506-T:

- [ ] One transcript type checked (6a, 6b, 6c, 7, or 8)
- [ ] Period(s) requested are formatted MM/DD/YYYY, no more than four
- [ ] Period(s) requested have ended AND the return has been processed (current-year Verification of Nonfiling only after June 15)
- [ ] Line 1a name matches return; Line 1b SSN/ID is correct
- [ ] If joint, Line 2a/2b filled; at least one spouse signing
- [ ] Line 3 = current address; Line 4 = last-return address (if different); Form 8822 filed if the IRS address of record is out of date
- [ ] Line 5 (if used) is ≤10 digits, no SSN, no name
- [ ] One form number entered (1040, 1040-SR, etc.)
- [ ] Authority checkbox checked; IRS will receive the form within 120 days of signing
- [ ] Routing address / fax number from the correct chart for the state where the user lived when the return was filed
- [ ] If using a lender's 4506-C, Form 4506-T is NOT also being submitted (avoid duplicate)

If any check fails, **stop and surface** to the user. Don't submit a form likely to be rejected.
