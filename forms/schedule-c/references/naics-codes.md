# Principal Business Codes for Schedule C Line B

Schedule C Line B takes the six-digit code from the "Principal Business or Professional Activity Codes" chart at the end of the Schedule C instructions. The chart is based on NAICS but is often broader than the six-digit NAICS taxonomy: for example, the IRS list has one code, 541400, for all specialized design (graphic, interior, industrial, fashion), where NAICS has four. Enter a code that appears in the IRS chart, not a NAICS code that only exists at census.gov. The codes below were checked against the chart in the 2025 Instructions for Schedule C (https://www.irs.gov/pub/irs-pdf/i1040sc.pdf); re-check them against each year's instructions. The Census Bureau maintains the underlying taxonomy at https://www.census.gov/naics/.

The choice matters for two reasons:
1. **IRS audit benchmarks**. The IRS compares expense ratios to peer averages by business code. Choosing a code where 70% expense ratio is normal makes a 70% expense ratio unremarkable; choosing one where 30% is normal makes the same return look like an outlier.
2. **Manufacturing vs. service**. Manufacturing codes (339900, 311800, etc.) come with an expectation of inventory and COGS. If the user makes physical products, prefer a manufacturing code over a generic retail one.

## Picking a code when nothing fits

The catch-all codes are:

- `999000` — Unclassified establishments (unable to classify; rarely a good idea; raises eyebrows)
- `541990` — All other professional, scientific, & technical services
- `561900` — Other support services
- `812990` — All other personal services

Use these only if no specific code from the IRS table matches. The 2025 instructions list about 300 codes; almost every business fits one of them.

## Changing the code year-over-year

A change in the business code on Schedule C from one year to the next implies a business change. If the actual business hasn't changed, keep the same code — the IRS may flag a code change for review. If the business genuinely changed (pivoted from photography to video editing, say), update the code and be ready to explain. A code that disappeared from the IRS chart (for example, 454110 for online sellers, or the six-digit consulting and design codes that the chart now groups as 541600 and 541400) must be replaced with the current chart code even if the business did not change.
